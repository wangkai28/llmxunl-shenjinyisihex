# M2 实验诊断记录

- 日期：2026-10-23
- 触发：M2 真实网关实验（data/m2_20261023_203206.json）表面「实验组收敛、对照组不收敛」，
  但 self_descriptions 揭示这是假阳性。

## 1. 现象

实验组误差序列下降（0.025→0.013→0.006→0.001→0.013，判为收敛），
对照组误差抖动（0.052→0.0→0.174→0.015→0.069，判为不收敛）。

但两组 LLM 的自我描述从头到尾都在说同一件事：
「a fully quiescent 64-unit network with zero active units across all bins」。

## 2. 根因（只读诊断确认）

- 初始膜电位 V ∈ [0.024, 0.990]，发放阈值 = 1.0 → 无单元能达到阈值。
- 初始 spikes 全零，且无输入时 V 只做纯泄漏衰减（均值 0.5274 → 0.4746）。
- 结论：**网络从构造起就是静默的，永远不会自发发放**。

因此「实验组收敛」的真实含义是：LLM 学会了预测「全零」，因为网络一直是全零。
这不是「回路让系统理解自己」，而是「网络死了，LLM 背下了答案」。

## 3. 两个必须修复的问题

1. **身体没有自发活动**：缺「内生节律/背景放电」，观察者面对的是尸体而非活体。
   方向：给 SpikingNetwork 加泊松背景自发活动（真实神经系统的基线放电）。
2. **判据噪声太大**：仅 5 个误差点，`converged` = 斜率正负号 + 头尾均值比大小，
   易被随机性骗。方向：加长实验 + 更稳健的收敛判定（p 值/效应量）。

## 4. 修复计划

- 先修问题 1（身体活起来），再重跑实验看效果；
- 问题 2（判据稳健性）随后单独处理。

## 5. 进展记录

### 5.1 身体活起来（已完成，commit 069f05c）

给 `SpikingNetwork` 加泊松背景自发活动（`background_rate` / `background_strength`），
用 `self.rng` 保证同 seed 可复现。参数扫描后选 `rate=0.05, strength=0.6`
（自发放电率约 5.6%，健康区间）。

重跑 60 步实验：网络活了，观察者开始「回头看自己之前的说法并修正」
（self_descriptions 出现 contradicting my prior claim / resolving earlier
inconsistent claims），但两组都未收敛（误差点仅 5 个，噪声主导）。

### 5.2 判据升级（已完成，commit a0cc800）

`convergence` 从「斜率正负号 + 头尾均值」升级为 bootstrap 显著性：

- 配对重采样（x、y 用同一 idx 采样），避免破坏 x-y 配对；
- 输出单侧 p 值（重采样斜率 >= 0 的比例）与 95% 置信区间；
- 收敛判定 = p < 0.05 且尾段均值 < 头段均值；
- 用闭式解算斜率（`_least_squares_slope`），消除 polyfit 病态警告。

### 5.3 加长实验 + 落盘 action（已完成，commit 56b807d）

- `ExperimentResult` 增加 `actions` 字段，记录每次 reflection 的 type/region/strength；
- M2 脚本 steps 60 → 300（30 个误差点），以便统计判定可信。

### 5.4 待办

- 写回「更实」：当前写回只喂给下一个时间步、强度靠 LLM 自报且偏弱，
  需诊断写回是否真正改变了网络，再决定是否改为持续/更强的扰动。

### 5.5 加长实验结论（300 步 / 29 误差点，data/m2_20261026_115926.json）

- 实验组：slope=+0.0037, p=0.9995, 头 0.091 → 尾 0.161（发散）
- 对照组：slope=+0.0093, p=1.0, 头 0.116 → 尾 0.251（发散）
- 结论：两组都「预测越来越差」，且趋势极显著（p≈1，即误差上升确凿）。
- 归因：写回强度太弱（LLM 自报 strength 0.1~0.32，网络阈值 1.0），
  实验组的 26 次注入对网络几乎无影响，闭环并未真正闭合。
- 硬结论：写回强度不解决，实验永远只会得到「发散」。
  下一步必须让写回真正能改变网络（强度规范化 + 持续扰动），
  而不是继续加长实验或调判据。

### 5.6 写回机制修复（commit d3712a7）

`Observer` 新增两个参数，让写回真正能改变网络：

- `writeback_duration`：注入持续的时间步数（默认 = observe_every，贯穿两个观察点）。
  原来只喂给下一个时间步，刺激来不及累积到阈值。
- `writeback_gain`：把 LLM 自报的意图强度（0~1）映射到足以跨越阈值的物理强度。

增益标定（模拟实验，背景 rate=0.05/strength=0.6）：

| gain | 写回后活动变化 |
| --- | --- |
| 1.0 | -5（无效） |
| 2.0 | +31（有效） |
| 3.0 | +33（有效） |
| 5.0 | +55（偏激） |

选 gain=2.5（甜点区间，给 LLM 自报 0.1~0.32 的强度留出有效映射空间）。

### 5.7 方案 A：prompt 改为「主动塑造者」（commit 14058a7）

`_build_prompt` 明确告诉 LLM：不是被动观察，而是主动用注入塑造网络，
让它对齐 self_description，并用「预测越准=越理解自己」作为隐含目标。

快速验证（连调 5 次）：5/5 主动注入，且稳定选择一个固定 bin 持续注入，
自我描述稳定成「a sparse left-biased observer that injects into bin 2」。
→ A 有效，LLM 从「被动观察」转为「主动塑造」，并形成稳定自我身份雏形。

### 5.8 方案 B：解耦写回（误差驱动）—— 待实现

A 虽有效，但 LLM 注入决策仍带随机性/不可控性。B 把「写回」从 LLM 手里
收回，变成确定性的误差驱动控制律：

- 上一轮预测误差大 → 自动写回扰动（重新校准）；
- 误差小 → 不写回（保持稳定）。
- LLM 仍负责预测 + 自我描述。

设计：Observer 新增 `writeback_policy`，取值 `"llm"`（现状）或
`"error-driven"`，A/B 可并存对比。

### 5.9 方案 A/B 实现完成（commit 14058a7 / cd37f71 / 81075a2）

- A：`_build_prompt` 改为「主动塑造者」（14058a7），快速验证 5/5 主动注入。
- B：`Observer` 新增 `writeback_policy`（llm/error-driven）+ `feedback_error()`，
  `experiment` 在算出误差后喂回（cd37f71）。
- 对比脚本：同时跑 llm / error-driven / readonly 三组（81075a2）。

error-driven 策略：误差 > threshold 才写回，写回强度用 LLM 报的 region，
但强度乘 writeback_gain；误差小则不写回。默认 threshold=0.15。

### 5.10 A/B 对比结论：全部发散，指标选错（data/m2_20261026_131614.json）

三组（llm / error-driven / readonly）预测误差全部随时间是上升的：

| 组 | 斜率 | p |
| --- | --- | --- |
| A llm | +0.0020 | 0.997 |
| B err-driven | +0.0027 | 0.938 |
| 对照 readonly | +0.0079 | 1.0 |

写回让误差恶化速度减缓约 3 倍（0.008 → 0.002），但不足以逆转成收敛。

根本结论：「预测误差收敛」不适合作为涌现判据——网络含泊松随机背景，
下一时刻状态本质不可精确预测，误差有随机性下限，永远下不去。

### 5.11 判据转向：自我叙事一致性（commit 8b0c560）

改判据为「观察者身份连续性」：

- `Reflection` 新增 `identity_continuity`：LLM 每次反思自评「我还是不是同一个我」(0~1)。
- `narrative_coherence()`：度量 identity_continuity 的均值 + 标准差，
  均值 ≥0.8 且 std ≤0.15 判为「身份稳定」。
- 用 LLM 自评而非外部向量相似度：自我连续性本应由主体自己评判，
  更贴合「自我认知」命题，且不引入 embedding 依赖。

目标：观察 A/B/对照三组，谁能让观察者形成更稳定的「我是谁」。

### 5.12 叙事一致性首个结果（data/m2_20261026_141658.json）

| 组 | coherent | identity 均值 | std |
| --- | --- | --- | --- |
| A llm（主动塑造） | ✅ | 0.869 | 0.064 |
| B err-driven | ✅ | 0.815 | 0.103 |
| 对照 readonly | ❌ | 0.770 | 0.095 |

观察点：

- A 组自我描述高度连贯：emerging → maintaining a focused pulse → sustaining，
  观察者「主动塑造并持续维护一个状态」，身份连续性最高、波动最小。
- 对照组每次被动复述网络状态，无「我在维持什么」的主体性，身份连续性最低。
- 结论：写回（尤其 A 的主动塑造）让观察者形成更稳定的自我身份，
  是「自我认知涌现」的可度量雏形。

诚实边界：

- 三组 identity_continuity 都偏高（0.77~0.87），因 LLM 本有「我是同一助手」惯性，
  A 组优势（约 0.1）真实但不算巨大，需多轮验证其可复现性。
- 旧「预测误差」指标仍全部发散，印证「预测随机网络」这个目标本身选错了。

### 5.13 可复现性验证（commit 21d0318）

验证「A 组叙事一致性优于对照」是否可复现：

- `paired_sign_test(a, b)`：配对符号检验，判断 A 是否稳定优于 B（单侧二项检验，
  正态近似 + 连续性校正，不引入 scipy）。
- `examples/replication.py`：跑 N 轮（默认 5），每轮不同 seed（100+r），
  A（llm 主动塑造）vs 对照组（readonly）配对比较，输出 identity_continuity 均值。
- 每轮 steps=200（20 个观察点），平衡时间与统计功效。

## 6. M2 阶段性结论（诚实负面）

当前规模下，**未观测到「自我认知涌现」的可复现证据**：

1. 「预测误差收敛」指标选错——含随机性的网络本质不可精确预测，误差有随机下限。
2. 「叙事一致性」指标——效应不稳定，5 轮无法复现。根因：LLM 本有「我是同一助手」
   的强惯性，identity_continuity 天然偏高（0.8~0.99），写回与否难以在已饱和的
   指标上拉开差距。

这是负面但诚实的结论。下一步方向待定：改进实验设计 vs 接受当前规模未涌现。

## 7. 扩大网络规模：稀疏重构（commit 4bdf389）

### 7.1 发现并修正的隐藏 bug

旧 `_hebb_update` 用 `np.outer(fired, fired)`，会让「所有同时发放的单元对」之间
凭空创建连接。验证：跑 500 步后网络从 10% 稀疏变成 70%+ 近全连接。

含义：之前所有实验跑的网络本质上不是真稀疏网络，而是「跑着跑着糊成一团」的网络。
旧实验结论（含「未观测到涌现」）严格说建立在有 bug 的网络上。

修正为科学正确的 Hebb：只在「已存在的突触」上强化，不凭空造突触。
这正是「扩大规模」的必要前提——否则旧 bug 会让大网络瞬间糊成全连接、内存爆炸。

### 7.2 稀疏重构

- 新增 `sparse.py`：COO 稀疏矩阵（numpy 数组存储，无 scipy 依赖）。
- `SpikingNetwork.W` 从稠密 N×N 改为 COO；`step` 的突触累加用 `np.bincount`，
  `_hebb_update` 只更新已存在的边，符号跟随每条边自己的 data。
- 性能：20000 单元（800 万条边）每步约 309ms；旧实现 8192 单元就 2.3s/步、
  20000 单元直接内存爆炸。
- 全量 63 测试通过。

### 7.3 扩大规模后暴露：E/I balance 未做对（活动率失控）

修正 Hebb 后，网络活动率随规模失控：

| 规模 | 活动率均值 | 标准差 | 峰值 |
| --- | --- | --- | --- |
| 64 | 7.5% | 4.6% | 18.8%（健康） |
| 1000 | 33.1% | 28.6% | 73.6% |
| 5000 | 33.4% | 37.7% | 91.4% |
| 20000 | 33.0% | 44.2% | 97.2%（接近全爆） |

根因：Dale 法则只是「随机 20% 抑制单元」，但抑制连接的强度与兴奋连接相同。
大网络里兴奋正反馈累积放大，抑制兜不住，导致全体一起爆。

方向：给抑制单元单独的、更强的连接强度（神经科学标准 E/I balance 做法），
例如 `inhibitory_weight_scale`（抑制突触权重是兴奋的 2-3 倍），再重扫参数。
这是「扩大网络」的必经之路——不修 E/I，扩大只是放大一个癫痫网络。

### 7.4 抑制强度扫描：只能缓解，不能根治（根因是全局同步振荡）

inhibitory_weight_scale 扫描（活动率均值 ± 标准差）：

| iws | n=1000 | n=5000 | n=20000 |
| --- | --- | --- | --- |
| 1.0 | 33.3%±28.4 | 33.3%±37.9 | 33.3%±44.1 |
| 3.0 | 32.0%±17.0 | 33.3%±21.6 | 33.3%±29.1 |
| 8.0 | 17.7%±4.8 | 20.2%±6.1 | 20.7%±5.3 |

时间序列（n=5000, iws=3.0）揭示真相：活动率陷入周期性「爆发-熄火」循环
（3% → 53% → 44% → 3% → 53% → 44% ...），一步自相关 -0.5。

根因：不是「兴奋过强」，而是**全局同步振荡**。均匀随机连接（rng.choice 全网络
均匀采样）+ 同质单元，诱发全体同步爆发-熄火。真实大脑是「异步不规则」活动，
靠局部连接结构 + 异构参数 + 随机背景来去同步。

真正的解法不是继续加强抑制，而是**引入局部连接结构**（空间邻域连接，像真实皮层），
把网络从「全局同步」变成「局部异步」。

### 7.5 空间连接 + 异质性（commit 8403143 之后）

实现空间局部连接（一维环、距离高斯衰减 `spatial_scale`）与异质阈值
（`threshold_noise`），扫描发现 `spatial_scale≈12` 时 5000 单元网络
活动率 14.3%、标准差 1.7%、自相关 -0.006（健康异步，无振荡）。

但跨规模验证失败：固定参数下 64 单元 28.8%（振荡）、20000 单元内存爆炸。
改「空间尺度=规模比例」也不行，活动率随规模单调漂移（0.9% → 27.6%）。

### 7.6 重新诊断：输入均值其实稳定，问题在涨落/相关性

逐单元输入诊断（n=64/500/5000）：平均兴奋输入约 0.46、抑制约 -0.5，净输入
-0.08~-0.11，**不随 N 增长**。因此「总输入随 N 增长导致同步爆发」的假设是错的。

真正的问题在「涨落与相关性」：大网络一旦有较多单元同时发放，兴奋通过共享连接
互相强化，形成雪崩式同步。这是平衡网络（Brunel）要解决的深层问题——需要兴奋
与抑制在均值上精确抵消，活动由「输入的涨落」驱动而非均值驱动。

### 7.7 当前判断

继续试经验参数（空间尺度、抑制强度）无法根治。需要实现平衡网络的数学条件
（Brunel 平衡条件：E/I 平均输入精确抵消 + 活动由涨落驱动），这是方向 C 的真正
含义，尚未真正落实。这是一个需要扎实神经科学功底才能正确建模的问题。
