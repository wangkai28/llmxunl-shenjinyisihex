# M2 实验诊断记录

- 日期：2026-10-23
- 触发：M2 真实网关实验（data/m2_20261023_203206.json）表面「实验组收敛、对照组不收敛」，
  但 self_descriptions 揭示这是假阳性。

## 1. 现象

实验组误差序列下降（0.025→0.013→0.006→0.001→0.013，判为收敛），
对照组误差抖动（0.052→0.0→0.174→0.015→0.069，判为不收敛）。

但两组 LLM 的自我描述从头到尾都在说同一件事：
「a fully quiescent 64-unit network with zero active units across all bins」。

## 2. 根因（只读诊断确认）

- 初始膜电位 V ∈ [0.024, 0.990]，发放阈值 = 1.0 → 无单元能达到阈值。
- 初始 spikes 全零，且无输入时 V 只做纯泄漏衰减（均值 0.5274 → 0.4746）。
- 结论：**网络从构造起就是静默的，永远不会自发发放**。

因此「实验组收敛」的真实含义是：LLM 学会了预测「全零」，因为网络一直是全零。
这不是「回路让系统理解自己」，而是「网络死了，LLM 背下了答案」。

## 3. 两个必须修复的问题

1. **身体没有自发活动**：缺「内生节律/背景放电」，观察者面对的是尸体而非活体。
   方向：给 SpikingNetwork 加泊松背景自发活动（真实神经系统的基线放电）。
2. **判据噪声太大**：仅 5 个误差点，`converged` = 斜率正负号 + 头尾均值比大小，
   易被随机性骗。方向：加长实验 + 更稳健的收敛判定（p 值/效应量）。

## 4. 修复计划

- 先修问题 1（身体活起来），再重跑实验看效果；
- 问题 2（判据稳健性）随后单独处理。
