## 0. 一句话结论

在当前的「LLM 观察者 + 脉冲网络 + 数值指标」方法下，**未观测到自我认知涌现的可复现证据**；
过程中发现并修正了脉冲网络模型的四层动力学缺陷，实现了一个健康得多的平衡网络，
但「涌现」这个目标本身的方法论假设可能需要重新审视。

## 2. 发现并修正的网络动力学缺陷（四层）

1. **Hebb 语义 bug**：旧实现用 `np.outer(fired, fired)` 让「同时发放的单元对」
   凭空创建连接，500 步后网络从 10% 稀疏糊成 70%+ 近全连接。
   修正：Hebb 只在已存在的突触上强化。

2. **E/I 平衡缺失**：Dale 法则只随机 20% 抑制单元，但抑制连接强度与兴奋相同，
   大网络里兴奋正反馈累积、抑制兜不住。修正：`inhibitory_weight_scale`。

3. **全局同步振荡**：均匀随机连接 + 同质单元诱发全体同步爆发-熄火
   （活动率 33%、Fano>20）。诊断：问题不在兴奋过强，而在连接结构。

4. **规模不变性缺失**：突触强度不随连接数缩放，涨落随规模失控。
   修正：Brunel 平衡网络的 1/√K 缩放。

## 3. 平衡网络的实现与成果

`balanced_network.py` 实现的关键机制：

- 突触强度按 `1/√K` 缩放 → 涨落幅度与规模无关。
- 稀疏随机连接 + 分散突触延迟（`delay_max`）→ 打破同步。
- 结果：**分散延迟是打破同步的最后关键**，Fano 从 24.5 降到 1.1。

达到的成果：

- 网络能自发活动（不依赖背景硬泵）。
- 活动率跨规模稳定（18.7%，1/√K 缩放生效）。
- 中小规模（≤1000 单元）达到真异步不规则（Fano≈1，健康皮层状态）。

诚实边界：规模大到几万单元时，同步会回来（Fano 13）。攻最后一层的 5 个方向中
3 个失败（加强抑制、固定连接概率、抑制延迟更短都更糟），说明「任意规模严格异步」
需要精确复现 Brunel 论文完整参数集，超出试参能可靠达到的范围。

## 4. 涌现实验的诚实结论

两个指标都被否定：

1. **预测误差收敛**：含随机性的网络本质不可精确预测，误差有数学下限，永远不收敛。
2. **叙事一致性**：LLM 天生有「我是同一助手」的强惯性，identity_continuity 天然
   饱和（0.8~0.99）。健康网络上两组都 0.98+，写回与否测不出差异（差值 0.01）。

## 5. 方法论反思（核心）

「自我认知涌现」用「数值指标」观测，可能从假设上就不成立，原因有二：

- **网络侧**：我们把网络做健康了（异步、稳定、可预测），而一个稳定可预测的
  网络，观察者自然能稳定描述它，不需要「涌现」。
- **观察者侧**：LLM 本来就是「同一个模型」，它不会因为观察了一个网络就产生
  「新的自我」。identity_continuity 测量的是 LLM 的会话惯性，不是涌现。
