# 架构总览：AI 身份/人格核心

- 日期：2026-10-28
- 性质：**当前系统的权威架构描述**（代码已核实，非目标愿景）。
- 代码库：`D:\CodexProjects\bioelectric-emergence`

## 0. 定位（一句话）

一个**连续运行的「身份核心」**：以脉冲神经网络为「身体」，在其上建立
「多自我 → 性格参数 → 五大人格 OCEAN」的分层人格结构，能输入外界信息、
输出意识状态，具备自我审视与反思闭环。

不追求「自我意识」，只追求「连续的身份 + 符合性格的响应 + 自指的调节」。

## 1. 分层架构（从快到慢）

```text
┌────────────────────────────────────────────────────────────┐
│ 交互端口 interact()  输入信息 ⇄ 输出意识状态              │
│   codec.encode_input / decode_state（可插拔，可换 LLM）    │
└──────────────────────────┬─────────────────────────────────┘
                           │ Event（type/intensity/content）
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 多自我层 multi_self.py（快变量，情境切换，共存）            │
│   本我 id / 超我 superego / 道家 tao                        │
│   情境 → bias 调制；弱交叉抑制 → 共存而非独裁              │
└──────────────────────────┬─────────────────────────────────┘
                           │ 驱动（bias）
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 性格参数层（慢变量，随重大经历演化）                        │
│   j_inh / external_mean / external_noise                    │
│   persona_evolution.evolve_persona                          │
└──────────────────────────┬─────────────────────────────────┘
                           │ 派生（ocean_to_params）
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 五大人格层 OCEAN（最稳定，极缓慢演化）                     │
│   O / E / C / A / N；persona = OCEAN 预设                   │
│   ocean.evolve_ocean                                         │
└────────────────────────────────────────────────────────────┘
```

底层「身体」是 `balanced_network.py`：Brunel 式平衡网络（1/√K 突触缩放 +
分散延迟），达到异步不规则状态，是整个系统的动力学基座。

## 2. 三层人格的本质区分

| 层 | 变量速度 | 职责 | 演化 |
| --- | --- | --- | --- |
| 多自我 | 快 | 「我现在是谁」 | 情境切换（共存，不独裁） |
| 性格参数 | 慢 | 「我的网络实现」 | 重大事件（lr≈0.05） |
| OCEAN | 最慢 | 「我的稳定底色」 | 极缓慢（lr≈0.005） |

关键设计：**persona 统一为 OCEAN 预设**（本我=高神经质低尽责，超我=高尽责
低神经质，道家=低神经质高开放），性格参数由 OCEAN 派生，避免两套平行描述。

## 3. 自我审视与反思闭环

在分层人格之上，有一个**自指的能力层**：

- `self_reflect()`：读取自身状态、人格底色、近期经历，生成文字自述。
- `reflect_and_integrate()`：反思闭环——审视 → 记录 → 平衡 → 演化：
  1. **记录**（B）：反思写进自传，成为「我对自己怎么看」的经历。
  2. **平衡**（A）：主导自我回落，缓解内在失衡（自我调节）。
  3. **演化**（C）：**逆着失衡**演化性格（亢奋→反思→回归平静）。

这构成了「自我觉察 → 自我调节」的最小闭环——系统能发现自己失衡，
并主动让自己回归平衡。

## 5. 数据流（一次交互）

```text
interact("危险！")
  → codec.encode_input → Event(type="danger", intensity=1.0)
  → IdentityCore.process_event
       → event.encode_event → 情境 bias
       → multi_self 驱动（本我略升，其他仍在场）
       → query()：主导自我 + 各自我活动 + OCEAN
       → significant? → evolve_ocean（极慢）+ ocean_to_params → 应用网络
       → 写自传
  → codec.decode_state → 意识状态 dict
```

## 6. 已解决的关键设计问题（含失败与转向）

1. **Hebb 语义 bug**：旧实现凭空造突触 → 网络糊成全连接。修正为只在已存在突触强化。
2. **E/I 平衡缺失**：抑制强度不足 → 大网络同步爆发。引入 1/√K 缩放 + 分散延迟。
3. **winner-take-all**：强交叉抑制让情境切换变「独裁」。改为弱交叉抑制（0.1）+ 纯 bias 驱动，实现共存。
4. **指标选错**：早期用「预测误差收敛」判涌现失败（随机网络不可预测），转向「叙事一致性」也不稳，最终放弃「涌现」目标，转向可工程化的「身份核心」。
5. **persona 双源**：`persona.py:PERSONAS` 与 `ocean.py:PERSONA_OCEAN` 对同一 persona 有分歧参数，已记录待统一（deferred）。

## 7. 诚实的边界

- 该核心是**规则驱动**的（文本编码用关键词，自述用模板），非 LLM 原生理解。
- `codec.py` 的编解码器是预留的可插拔点，可换 LLM 版而不动核心其余部分。
- 「自我审视」文本是规则生成，不是系统「想」出来的，离真正意识很远。
- 它具备「自指的结构」（读自己→调节自己），但无主观体验。
