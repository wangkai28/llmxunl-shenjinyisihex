# 架构总览：AI 身份/人格核心
- 日期：2026-10-29
- 性质：**当前系统的权威架构描述**（代码已核实，非目标愿景）。
- 代码库：`D:\CodexProjects\bioelectric-emergence`

## 0. 定位（一句话）
一个连续运行的「身份核心」：以脉冲神经网络为「身体」，人格理解（意识·情绪·性格）
由神经网络（LLM 蒸馏）承担，人格演化从网络学习中涌现，能输入外界信息、输出
意识状态，具备自我审视与反思闭环。

不追求哲学上的「自我意识」，只追求「连续身份 + 符合人格的响应 + 自指的调节」，
其中人格相关的能力**全部由神经网络学习得到，而非手写规则**。

## 1. 分层架构（从快到慢）
```text
┌────────────────────────────────────────────────────────────┐
│ 交互端口 interact()  输入文本 ⇄ 输出意识状态              │
│   9 维统一人格模型（意识2+情绪2+性格5，LLM 蒸馏）          │
└──────────────────────────┬─────────────────────────────────┘
                           │ 情绪→情境 / 性格→物理量 / 意识→输出
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 多自我层 multi_self.py（快变量，情境切换，共存）            │
│   本我 id / 超我 superego / 道家 tao                        │
│   情境 → bias 调制；弱交叉抑制 → 共存而非独裁              │
└──────────────────────────┬─────────────────────────────────┘
                           │ 驱动（bias）
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 性格参数层（慢变量，从网络学习痕迹读出）                    │
│   j_inh / external_mean / external_noise                    │
│   涌现式：emergent_personality.read_personality              │
└──────────────────────────┬─────────────────────────────────┘
                           │ 读出
                           ▼
┌────────────────────────────────────────────────────────────┐
│ 五大人格层 OCEAN（最稳定，极缓慢演化）                     │
│   O / E / C / A / N；persona = OCEAN 预设                   │
└────────────────────────────────────────────────────────────┘
```
底层「身体」是 `balanced_network.py`：Brunel 式平衡网络（1/√K 突触缩放 +
分散延迟 + 稳定 Hebb），达到异步不规则状态，是整个系统的动力学基座。

## 2. 人格理解：9 维统一模型（LLM 蒸馏，核心新增）
系统对「意识·情绪·性格」的理解，统一由一个 9 维 MLP 承担，它由 LLM 蒸馏训练：

| 层 | 维度 | 范围 | 含义 |
| --- | --- | --- | --- |
| 情绪 | valence | [-1,1] | 效价（愉快↔不愉快） |
| 情绪 | arousal | [-1,1] | 唤醒度（平静↔激动） |
| 性格 | openness | [0,1] | 开放性 |
| 性格 | extraversion | [0,1] | 外向性 |
| 性格 | conscientiousness | [0,1] | 尽责性 |
| 性格 | agreeableness | [0,1] | 宜人性 |
| 性格 | neuroticism | [0,1] | 神经质 |
| 意识 | self_clarity | [0,1] | 自我清晰度 |
| 意识 | agency | [0,1] | 主体性/主动性 |

训练路径：LLM（qwen3.7-plus，aigw 网关）批量标注「文本 → 9 维」，
再训练 MLP 蒸馏，权重固化（`data/unified_personality_model.npz`），
之后离线判断、零成本。这是「类似大模型里提前训练出人格设定」的实现。

## 3. 人格演化：从网络学习中涌现（核心新增）
人格演化不再有手写 if-else（`evolve_ocean`），而是「经历 → 网络学习 → 人格读出」：

```text
情绪经历 (valence, arousal)
  → emotion_experience：情绪 → 主导自我核心激活
  → 脉冲网络 Hebb 学习（稳定：绝对上限 weight_max + 遗忘 weight_decay）
  → read_personality：从网络连接读出人格（冲动性/克制/活性/稳定性）
```

验证过的涌现性质：
- 危险经历 → 本我回路固化 → 冲动性上升。
- 道德经历 → 超我回路固化 → 克制上升。
- 平静经历 → 本我回路遗忘 → 冲动回落。
- 人格固化后，反思调节变慢（越固化越难被改变）。

## 4. 自我审视与反思闭环
- `self_reflect()`：读取自身状态、人格、经历，生成文字自述。
- `reflect_and_integrate()`：审视 → 记录 → 平衡 → 逆失衡演化。
构成「自我觉察 → 自我调节」的最小闭环。

## 6. 数据流（一次交互，统一模型路径）
```text
interact("我清楚知道自己是谁")
  → unified_model.predict_text → 9 维向量
       → 情绪(valence,arousal) → emotion_to_context → 驱动多自我
       → 性格(OCEAN) → ocean_to_params → 派生物理量 → 应用网络
       → 意识(self_clarity,agency) → 进输出
  → query()：主导自我 + 各自我活动 + OCEAN + 意识维度
  → decode_state → 意识状态 dict
```

## 7. 已解决的关键设计问题（含失败与转向）
1. Hebb 语义 bug：凭空造突触 → 网络糊成全连接。修正为只在已存在突触强化。
2. E/I 平衡缺失 → 大网络同步爆发。引入 1/√K 缩放 + 分散延迟。
3. winner-take-all：强交叉抑制让情境切换变独裁。改弱交叉抑制（0.1）实现共存。
4. 指标选错：早期「预测误差收敛」判涌现失败，转向「叙事一致性」也不稳，
   最终放弃「涌现」目标，转向可工程化的「身份核心」。
5. Hebb 发散：相对上限导致权重爆炸（3700 倍）。改绝对上限 + 遗忘。
6. 手写规则天花板：关键词情绪理解对成语全瞎（33%）。改 LLM 蒸馏（92%）。
7. 克制维度读不出：抑制突触不可塑。改「抑制可塑性 + 从超我回路读出克制」。
8. persona 双源：`persona.py:PERSONAS` 与 `ocean.py:PERSONA_OCEAN` 分歧，待统一。

## 8. 诚实的边界
- 人格理解（9维模型）是 LLM 蒸馏的小型 MLP，字符 n-gram 特征，准确率约 92%，
  非 LLM 原生、非完美语义理解；对更冷门表达可能降。
- 「自我审视」文字是规则模板生成，不是系统「想」出来的。
- 系统具备「自指结构」（读自己→调节自己），但无主观体验，离真正意识很远。
- 「意识」维度只取「自我清晰度」「主体性」两个可操作化的心理学维度。
