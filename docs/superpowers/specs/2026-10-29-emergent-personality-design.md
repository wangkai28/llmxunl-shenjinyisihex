# 人格涌现（有引导）设计 — 方案 C2/B

- 日期：2026-10-29
- 状态：架构设计（待评审）
- 定位：人格演化从「手写规则」改为「网络学习的涌现」——经历通过 Hebb 学习
  改变网络，人格从网络学习痕迹中读出。

## 0. 一句话

去掉手写的 `evolve_ocean` 规则，让「情绪经历 → 网络学习 → 人格读出」成为
内生于系统的闭环：经历塑造网络，网络状态定义人格。

## 1. 核心闭环

```text
情绪经历 (valence, arousal)  ← 学习情绪层（已有 MLP，LLM 蒸馏）
        ↓ 作为学习信号
脉冲网络 Hebb 学习（稳定化：绝对上限 + 遗忘）
        ↓ 学习痕迹固化在连接
读出人格 ← 从网络连接/动力学状态读（替代手写 evolve_ocean）
```

## 2. 必须先修的地基：Hebb 发散

诊断：当前 `_hebb_update` 用 `w_max = 最大权重 * 5`（相对值），导致正反馈发散——
权重涨 → w_max 涨 → 权重继续涨。诊断实测：危险经历 300 步后，核心兴奋边强度
从 40.9 涨到 151683（3700 倍），失控。

修复：
- 权重加**绝对上限** `weight_max`（固定值，如 2.0）。
- 加**遗忘/衰减** `weight_decay`（学习有进有出，能消退）。

这是 C2 的前提——不稳定学习谈不上涌现。

## 3. 人格从网络读出（替代 evolve_ocean）

人格参数不再是手写映射，而是从网络学习痕迹读出的可观测特征：

| 读出的量 | 含义 | 网络来源 |
| --- | --- | --- |
| 冲动性/神经质 | 核心区兴奋边平均强度 | 兴奋边越强越易冲动 |
| 克制/尽责 | 核心区抑制边平均强度 | 抑制越强越自律 |
| 活性/外向 | 核心区活动率 | 活动越高越外向 |
| 稳定性 | 活动率的波动 | 波动越大越不稳 |

经历 → Hebb 改变这些网络特征 → 人格读出随之变化。演化「涌现」于学习，
不再有独立的演化规则。

## 4. 情绪坐标如何驱动学习（引导信号 B）

情绪坐标 (valence, arousal) 作为学习信号，决定「哪个自我核心被强化/弱化」：

- 高唤醒 + 负效价（愤怒/恐惧）→ 强化本我核心（应激回路）。
- 正效价 + 低唤醒（平静）→ 强化道家核心（从容回路）。
- 负效价 + 低唤醒（低落）→ 强化压抑回路。

即：情绪经历激活对应核心 → Hebb 固化 → 该人格侧面增强。
这是「有引导的涌现」——引导信号是情绪坐标，不是手写 if-else。

## 5. 里程碑

1. **M1 地基修复**：Hebb 绝对上限 + 遗忘，验证学习稳定（不再发散）。
2. **M2 读出实现**：从网络状态读出人格参数，替代 evolve_ocean。
3. **M3 情绪驱动闭环**：情绪坐标驱动核心强化，形成「经历→学习→人格」闭环。

## 6. 非目标

- 不追求完全无引导的「真涌现」（已证明不稳定）。
- 保留学习情绪层（MLP）作为引导信号的来源。
- 首版不追求人格读出的高精度，只证明「网络学习 → 人格变化」的闭环成立。
