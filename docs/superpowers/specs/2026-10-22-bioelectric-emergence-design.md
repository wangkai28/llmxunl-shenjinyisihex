# 生物电涌现实验设计（方向 C）

- 日期：2026-10-22
- 状态：架构设计（待用户评审）
- 定位：一个**独立、可证伪**的研究实验项目，研究「自我认知反应」能否在一套
  「生物电脉冲网络 + LLM 观察者」的闭合回路中**涌现**，而非被硬编码。
- 与「人造元婴」的关系：独立开发，但底层网络与 LLM 观察者的对外接口从设计上
  预留，使其将来可作为人造元婴的底层身体插入。

## 0. 一句话

用一群带 Hebb 式可塑性的生物电脉冲单元构成一个稀疏神经网络，上面挂一个 LLM
观察者，形成「读 → 反思 → 写回 → 再读」的闭合回路；观察网络的实际状态与 LLM
持有的自我表征是否在这个回路中逐渐对齐——若对齐，则判定自我认知涌现。

## 1. 背景与动机

本项目源于一组哲学性追问，最终收敛为一个可验证的技术假设：

- 智能的涌现已可在群体效应中观察到（蚁群、鸟群、脉冲网络）；
- 但「智能行为」与「自我认知」是两件事：一群单元再复杂，若没有一条
  「回头指认自己」的闭合回路，它只会涌现智能，不会涌现自我；
- 因此本实验不追求「更强的智能」，只追求「一个关于自身的稳定表征，并据此
  反向塑造自身」的闭环是否出现。

术语借用佛教唯识的「阿赖耶识」作为比喻性框架，但本实验**不承诺任何宗教或
形而上学的实义**，只取其中可工程化的功能描述：储藏、熏习、现行、连续性。

## 2. 核心假设与判定标准（行为闭环指标）

### 2.1 假设

当「LLM 观察者 → 底层网络」的写回通路闭合时，网络会逐渐形成一个关于自身的
稳定表征，并用它引导自身演化，使「实际状态」向「自我表征」收敛。

### 2.2 成功判据（须同时满足三条）

1. **自我表征形成**：LLM 通过反复读取，形成一份关于网络整体状态的稳定描述，
   且该描述随演化**保持连续**（非每次随机生成）。
2. **写回产生定向影响**：LLM 依据自我表征写回网络后，网络状态**确实朝向该
   表征预期的方向变化**。
3. **闭环收敛**：网络「实际状态」与 LLM「自我表征」之间的偏差随时间**缩小并
   稳定**（即「以为的自己」与「实然的自己」逐渐合一）。

### 2.3 证伪对照

设置一个「无写回」对照组：同样读、同样反思，但反思结果**不写回**网络。若
对照组始终不出现「表征-实际对齐」，而实验组出现，才能证明是**闭合回路**（而
非单纯的语言能力）造成了自我认知。对照组是实验结论成立的必要条件。

## 3. 总体架构（分层混合）

```text
┌─────────────────────────────────────────────────────┐
│  上层：LLM 观察者（阿赖耶识层 / 自我回路）            │
│   读（活动快照 + 历史反思） → 反思 → 写回 → 再读      │
│   介入节律：固定 N 步打底 + 事件触发                  │
└──────────────────────┬──────────────────────────────┘
                       │ 读 / 写回（可插拔 Provider）
┌──────────────────────▼──────────────────────────────┐
│  底层：生物电脉冲网络（身体 / 神经网络）              │
│   膜电位累积 → 过阈值发放 → 不应期（全有或全无）      │
│   突触带 Hebb 式可塑性（会学习、会记忆、会遗忘）      │
│   稀疏、局部连接，矩阵批量计算                        │
└─────────────────────────────────────────────────────┘
```

## 4. 底层设计（生物电脉冲网络）

### 4.1 单元模型（脉冲神经元）

采用 leaky integrate-and-fire（LIF）作为最小模型，仅保留下列机制：

- **膜电位累积**：`V += (外部输入 + 突触输入 - 泄漏) * dt`
- **阈值发放**：`V >= V_threshold` 时发放一个脉冲，随后 V 重置
- **不应期**：发放后一段固定时间内不再发放

这是「简单规则单元」的原始样本，单个单元极傻，规模上去后才可能涌现。

### 4.2 突触与 Hebb 式可塑性（熏习）

- 突触权重承载网络的历史记忆；
- 采用 Hebb 规则：**同时发放的神经元对，连接增强**；并附带衰减/遗忘项，
  使持续不用的连接退回、消失（对应「失稳制造回收」）；
- 可塑性是「会学习、会记忆」的关键一跃——没有它，网络没有历史，自我认知
  无从谈起。

### 4.3 拓扑与规模

- 稀疏、局部连接（不搞全连接），避免 N² 爆炸；
- 起步规模：数千个单元，先跑通闭环；
- 预留扩展接口：之后可迁移至 GPU / JAX / PyTorch，冲击十万级。

## 5. 上层设计（LLM 观察者 / 自我回路）

### 5.1 本体论设定（我是谁）

- **自我 = 整个底层网络本身**，不存在独立的「自我模块」；
- LLM **不是**自我，而是网络长出来的一根「自我指认的触角」；
- 自我认知 = 网络通过 LLM 回路回头看见自己、并被这次「看见」所改变。

### 5.2 读取通道（双通道）

LLM 同时读两层：

1. **当下活动快照**：底层网络的原始活动状态（哪群单元在放电、时空模式），
   压缩为 LLM 可消费的表征；
2. **历史反思记录**：LLM 自己过去的反思（种子），构成时间深度。

### 5.3 写回通道

LLM 把反思结果转成对底层网络的扰动：注入刺激、调制突触、或重置某区域。
写回是闭合回路的另一半，也是自我指涉真正发生的环节。

### 5.4 介入节律（混合）

- 固定节律打底：默认每 N 步读一次，保证闭环稳定、可复现；
- 事件触发加成：监测网络是否出现显著事件（大范围同步爆发、相变），触发则
  额外介入一次；
- 将来可扩展「LLM 自主决定何时看」，但首版不启用（保证可复现性优先）。

### 5.5 压缩是机制的一部分

海量活动压成低维表征这个动作，不是纯工程负担，它对应「转识」——把现行压成
种子。观察者只能看到压缩后的自己，这既是工程限制，也可能是「自我认知必然
有限」的来源。设计上把它视为一等公民，而非绕过它。

## 6. 技术选型

| 关注面 | 选型 | 理由 |
| --- | --- | --- |
| 语言 | Python | 生态成熟、原型快 |
| 底层计算 | NumPy 起步 | 数千单元足够快，零额外依赖 |
| 扩展路径 | JAX / PyTorch / GPU | 规模冲击时迁移 |
| LLM | 公司网关模型（deepseek / qwen / glm 等） | 走现有网关 |
| LLM 调用 | 可插拔 Provider 接口 | 模型可替换、可 mock，便于测试与成本控制 |
| 持久化 | D 盘本地（日志 / 反思记录 / 快照） | 遵循用户「数据在 D 盘」约定 |

## 7. 模块划分

每个模块一个清晰职责，可独立测试：

1. **脉冲网络核**（`spiking.py`）：LIF 单元、突触、Hebb 更新、脉冲传播。不依赖 LLM。
2. **快照与压缩器**（`snapshot.py`）：把网络活动压缩为 LLM 可消费表征。纯函数。
3. **反思记录存储**（`memory.py`）：保存 LLM 的历史反思（种子），可持久化。
4. **LLM Provider**（`llm_provider.py`）：统一读写接口，可插拔、可 mock。
5. **观察者回路**（`observer.py`）：编排「读 → 反思 → 写回 → 再读」的闭合循环，实现节律。
6. **行为闭环度量**（`metrics.py`）：量化「表征-实际偏差」，供判定收敛。
7. **实验编排**（`experiment.py`）：组装实验组 / 对照组，跑批、收集结果。

## 8. 数据流

```text
底层网络演化（LIF + Hebb）
       │  每 N 步 / 事件触发
       ▼
快照压缩 → LLM 观察者读入（快照 + 历史反思）
       │
       ▼
LLM 反思 → 生成自我表征 + 写回动作
       │
       ├──► 写回底层网络（实验组）  /  丢弃（对照组）
       │
       ▼
自我表征写入反思记录存储
       │
       ▼
度量：实际状态 vs 自我表征 的偏差 → 观察是否收敛
```

## 9. 错误处理与可复现性

- 确定性优先：底层网络与压缩器为纯函数 / 固定种子，保证可重放；
- LLM 调用失败时降级：记录失败、保留上轮自我表征、不中断实验；
- 所有反思、写回动作、度量结果写入 D 盘日志，可审计；
- 实验组与对照组共享同一随机种子与初始网络，只差「是否写回」一个变量。

## 10. 测试策略

- 单元测试：LIF 发放/不应期、Hebb 增强与衰减、压缩器维度正确、度量计算；
- 闭环测试：用 mock LLM 验证「读→反思→写回→再读」时序与节律正确；
- 对照测试：断言实验组与对照组仅「写回」一个变量不同；
- 收敛判定测试：构造一个必然收敛的玩具场景，验证度量能正确报告收敛。

## 11. 非目标

- 不承诺「智能涌现」或通用智能；只观察自我认知的闭环指标。
- 不追求规模军备竞赛；闭环的闭合方式优先于单元数量。
- 首版不启用「LLM 自主决定何时看」；不引入强化学习 / 复杂人格。
- 不与「人造元婴」项目在本阶段合并；只预留接口。

## 12. 里程碑

1. **M1 最小可跑闭环**：数十个单元，跑通「读 → 反思 → 写回 → 再读」，验证接口与节律。
2. **M2 行为闭环度量**：接入「表征-实际偏差」度量与对照组，能跑出可对比的结果。
3. **M3 规模放大**：数千单元，观察同步 / 波传播等动力学与自我表征的关系。
4. **M4 判定与结论**：根据行为闭环指标与对照组，给出「是否涌现」的可证伪结论。
