# 神经网络学习人格层 设计

- 日期：2026-10-28
- 状态：架构设计（待评审）
- 定位：人格参数**由神经网络从对话数据学习得到**，取代手写规则映射。

## 0. 一句话

用一个小型可训练神经网络，从「对话语句 → 情绪/人格量化参数」的标注数据中
学出人格理解能力，固化其权重，取代 `ocean.py`/`persona_evolution.py` 里手写的
if-else 与线性映射。

## 1. 目标

- 人格/情绪维度（委屈、内向、生气、开心等）量化成数值参数。
- 神经网络学会「输入语句 → 输出人格参数」的映射，权重固化后即「人格理解层」。
- 底层脉冲网络（SNN）继续当「身体」，提供动力学；人格理解层是它的「感知/决策前级」。

## 2. 架构

```text
对话语句
   │ 文本特征化（词袋 BOW，纯 numpy，无外部依赖）
   ▼
可训练 MLP（人格理解层）  —— 权重由对话数据训练、固化
   │ 输出人格/情绪参数向量
   ▼
映射到网络物理量（external_mean / noise / j_inh 等）—— 保留薄薄一层可解释映射
   ▼
脉冲网络身体（SNN）
```

人格理解层是「真的学出来的」；最后一层「参数→物理量」保留为薄映射，
以保证物理量仍在合法区间（可解释、可约束）。

## 3. 情绪与人格维度（有心理学依据的体系）

### 3.1 情绪状态：Russell 效价-唤醒度模型（连续二维）

情绪不是离散列表，而是**两个连续维度**构成的空间，所有情绪都是平面上一点：

| 维度 | 含义 | 范围 |
| --- | --- | --- |
| `valence` 效价 | 愉快 ↔ 不愉快 | [-1, +1] |
| `arousal` 唤醒度 | 平静 ↔ 激动 | [-1, +1] |

示例坐标（用于构造训练数据）：

| 情绪 | valence | arousal |
| --- | --- | --- |
| 开心 | +0.8 | +0.6 |
| 委屈/悲伤 | -0.7 | -0.4 |
| 生气/愤怒 | -0.7 | +0.7 |
| 放松/平静 | +0.6 | -0.7 |
| 焦虑/恐惧 | -0.5 | +0.6 |

这保证**覆盖完整、不靠举例枚举**——任何情绪都能表示为一个 (valence, arousal) 坐标。

### 3.2 人格特质：OCEAN 大五（沿用，五维 [0,1]）

人格用已有的大五 O/E/C/A/N，作为**稳定的特质层**（与情绪状态的二维模型
区分：情绪是快变量，人格是慢变量）。

### 3.3 训练数据格式

`(语句, 情绪标签 (valence, arousal))`。由我构造一批典型语句，覆盖情绪平面的
四个象限（愉快/不愉快 × 平静/激动）及中性区。规模约 100~200 条。

## 4. 模型与训练

- 输入：BOW 特征（关键词表计数）。
- 模型：小 MLP（输入 → 隐层 → 输出 2 维情绪坐标 (valence, arousal)）。
- 训练：手写反向传播（纯 numpy）或小批量梯度下降，MSE 损失。
- 固化：训练后保存权重到 D 盘，加载即用（无需再训练）。

## 5. 与现有系统的关系

- `ocean.py` / `persona_evolution.py` 的手写规则**保留但降级**为 fallback/对照，
  新的人格理解层优先使用。
- 身份核心 `IdentityCore` 可选接入「学习人格层」：对话输入 → 学习网络 → 情绪参数
  → 映射物理量 → 驱动 SNN。

## 6. 里程碑

1. **M1 数据 + 模型**：生成标注数据，训练 MLP 学会「语句→情绪参数」。
2. **M2 固化与评估**：保存/加载权重，评估在未见语句上的泛化。
3. **M3 接入身份核心**：学习人格层替代手写映射，驱动 SNN。

## 7. 非目标

- 不追求 LLM 级理解；这是「小型可训练网络学情绪映射」的证明。
- 首版不训练「人格演化」的规则（演化仍可由规则/后续学习）。
