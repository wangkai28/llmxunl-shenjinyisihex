## 1. M1 交付了什么

一个最小可跑闭环，用 `MockLLMProvider` 离线跑通「读 → 反思 → 写回 → 再读」：

- 底层 `SpikingNetwork`：LIF 脉冲神经元 + Hebb 可塑性 + 稀疏连接。
- 上层 `Observer`：`readwrite` / `readonly` 两种模式，`observe_every` 控制介入节律。
- 中间件：`snapshot`（活动压缩）、`memory`（反思记忆）、`llm_provider`（抽象 + Mock）。

## 2. 真实观察（probe.py）

64 单元网络，持续刺激核心区（0–7）：

- 稀疏连接：403 / 4096 ≈ 9.8%。
- 活动分布随步漂移，主要集中在核心区，外围零星散落 —— 网络在自发演化。
- Hebb 单测：两单元连续共发放 5 步，突触权重 0.000 → 0.819（一起发放则增强）。
- 核心区内部平均连接权重 0.270，高于外围 —— 活跃区域连接在固化。

## 3. M1 的诚实边界

- 语言层的「自我表征」是 Mock 写死的，不是真实反思。
- 写回是固定动作（往 region0 注入 2.0），不基于任何真实反思。
- 因此：底层（身体）会动、会记，但「自我指涉」尚未发生。
- M1 验证的是「回路转得起来」，不是「涌现了什么」。

## 4. 关键科学隐患（待 M3 前决策）

Hebb 更新用 `np.clip(W, 0, weight_max)`，负权重（抑制性连接）在第一步被清零。

- 后果：当前网络是「全兴奋性」，没有抑制。
- 风险：真实大脑的稳定 / 节律 / 竞争依赖兴奋-抑制平衡（E/I balance）；
  纯兴奋网络易退化为「全静默」或「全爆发」的癫痫态。
- 决策点：M3 研究同步 / 波传播 / 自我表征的动力学之前，必须先决定是否支持抑制
  （例如：保留负权重、引入独立抑制单元、或显式 E/I 结构）。

### 4.1 E/I balance 修复（已完成，commit b63d22c）

采用 Dale 法则（方案 B）：每个单元定型为纯兴奋或纯抑制（默认 20% 抑制），
作为 presynaptic 时其输出连接符号固定；Hebb 只调整 magnitude、不吞符号。

- 新增 `inhibitory_fraction` 参数，`is_inhibitory` 属性，`_sign` 符号矩阵。
- 测试：抑制单元输出连接为负、Hebb 保持抑制/兴奋符号不变。

### 4.2 修复后的诚实观察

持续刺激下，放电率随抑制比例单调下降（inhib 0.0→0.3：33%→20%），
抑制在压制峰值上起效（56%→45%），但均值与标准差几乎不变。

- 结论：Dale 法则抑制是**必要地基**（抑制能被正确表达），
  但还不足以产生真实 E/I balance 的振荡/同步/竞争动力学。
- 那需要更强/更短程/更局部的抑制连接，属 M3 的调参与结构细化，
  不在当前最小正确版的范围内。
